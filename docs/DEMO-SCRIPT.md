## 二、演示视频分镜脚本（2-3 分钟，9/13-15 录制）

- **画面**：黑客输入一段"看不见的代码"（U+200B 零宽空格在高亮编辑器里闪烁消失）→ 文件被提交进仓库

### 镜头 2 · 输入（0:15-0:30）
- **画面**：现场提交真实 GitHub 仓库 / 上传 ZIP / 粘贴本地目录（展示三种输入）
- **口播**：*"把仓库交给 CodeRisk Arcana，全程无需上传源代码——代码留在你手里，分析在云端完成。"*

### 镜头 3 · 6 节点流水线（0:30-1:00）⭐ 核心
- **画面**：OTEL 追踪面板逐节点点亮：Agent0 PITAX 规则层 → 侦察（提假设）→ 验证（工具证实/证伪）→ 深挖（攻击链）→ 裁判官（多源合议）→ 报告

- **亮点覆盖**：OTEL 追踪展示每一步 + Strands 生产级编排 + 三重交叉验证

### 镜头 4 · 攻击链可视化（1:00-1:30）
- **画面**：一条完整攻击链动画：文档投毒（Developer mode）→ 代码解析（隐藏字符+os.system）→ 提示词泄露 → 系统接管
- **口播**：*"这是模型自己推演出的完整攻击链——从一份被投毒的 README，到 AI 助手被完全劫持。报告不只是清单，是威胁剧本。"*
- **亮点覆盖**：真实漏洞库 demo 仓库展示

### 镜头 5 · Guardrails 拦截（1:30-1:45）⭐ 最出彩

### 镜头 6 · 集成能力（1:45-2:10）
