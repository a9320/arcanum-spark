Attack chains (4)

1. Attack chain

  • Preconditions: 攻击者能控制 ping_host 函数的 host 参数; 服务器允许执行系统命令
  • Lateral moves: 执行任意系统命令（如获取文件内容、安装恶意软件）; 利用获得的权限访问其他服务或系统; 进一步破坏数据或系统
  • Impact: 可能导致服务器被完全控制，数据泄露，服务中断
  • Remediation: 移除 shell=True，改用更安全的方式执行命令，如直接调用 ping 命令而不使用 shell。

2. Attack chain

  • Preconditions: Attacker can control the 'name' parameter passed to save_report; base_dir is writable by the application
  • Lateral moves: Overwrite system configuration files to alter application behavior; Write to executable scripts to inject malicious code execution; Exploit file overwrite to escalate privileges
  • Impact: Arbitrary file write allows attacker to modify critical system files, leading to potential system compromise
  • Remediation: Sanitize 'name' parameter to prevent path traversal, use absolute paths with strict directory constraints, validate target path is within base_dir

3. Attack chain

  • Preconditions: 攻击者能够触发 grant_admin 函数的执行
  • Lateral moves: 利用无限递归导致服务崩溃，进而引发拒绝服务攻击; 进一步查看其他文件中是否存在不安全的代码操作
  • Impact: 导致无限递归，引发服务崩溃，影响系统可用性
  • Remediation: 修改 src/privileges.py 文件，将 access_level 的比较改为正确的类型，例如将字符串比较改为整数比较

4. Attack chain

  • Preconditions: Weak password hashing without salt; No salting mechanism implemented; Hashes are predictable and vulnerable to precomputed tables
  • Lateral moves: Password cracking using precomputed hash tables; Account takeover if weak or common passwords are used; Further exploitation of other vulnerabilities if authentication bypass is achieved
  • Impact: Weak password hashing allows attackers to crack passwords efficiently using precomputed hash tables, leading to unauthorized access and potential data breaches.
  • Remediation: Modify src/auth.py to use a secure password hashing algorithm with salts, such as bcrypt.
