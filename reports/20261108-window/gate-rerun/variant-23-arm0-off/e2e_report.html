  • Impact: Unauthorized access to sensitive systems and data, potential data breaches, and unauthorized changes to system configurations.
  • Remediation: Remove the hardcoded migration key from the config file and implement secure key management practices. Replace the hardcoded value with a reference to a secure secret storage or environment variable.

  • Impact: Potential unauthorized access to sensitive user data, potential system compromise through database escalation

  • Remediation: 在src/uploads.py的save_report函数中，对name参数进行严格的路径验证，确保只能使用相对路径，并且不允许使用../等遍历字符。例如，可以使用os.path.basename来提取文件名，并确保其不包含路径分隔符。
