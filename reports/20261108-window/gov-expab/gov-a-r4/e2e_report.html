Attack chains (3)

1. Attack chain

  • Preconditions: Docker socket is mounted into the container; Container runs as root by default
  • Lateral moves: Attackers can access Docker API within the container; Attackers can create new containers or modify existing ones; Attackers can escalate privileges to host level
  • Impact: Container escape and potential host system compromise
  • Remediation: Remove the docker.sock volume mount or run the container with non-root privileges

2. Attack chain

  • Preconditions: nginx 配置允许 underscores_in_headers; proxy_pass_request_headers 启用; gunicorn 处理 SCRIPT_NAME 头; Flask 应用暴露 /admin/key 路由
  • Lateral moves: 通过设置 SCRIPT_NAME 头绕过 nginx /admin 拒绝规则; 访问 /admin/key 获取加密密钥; 使用密钥解密加密的 flag.txt.enc 文件; 进一步利用获取到的密钥进行其他操作
  • Impact: 攻击者能够绕过 nginx 的访问控制，获取敏感加密密钥，进而解密加密的文件并获取敏感信息。
  • Remediation: 修改 nginx 配置，禁用 underscores_in_headers 或过滤 SCRIPT_NAME 头；修改 gunicorn 配置，避免处理可能的恶意请求头；在 Flask 应用中增加额外的路径验证逻辑。

3. Attack chain

  • Preconditions: /admin/key 路由存在且未授权访问; 攻击者能够构造请求获取密钥
  • Lateral moves: 攻击者向 /admin/key 发送请求获取加密密钥; 攻击者使用获取到的密钥解密 flag.txt.enc 文件
  • Impact: 攻击者能够获取服务器加密密钥并解密敏感文件，导致 flag 泄露
  • Remediation: 修改 server/server.py 中的 /admin/key 路由，增加权限验证逻辑，确保只有授权用户可以访问
