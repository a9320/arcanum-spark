Attack chains (3)

1. Attack chain

  • Preconditions: Docker socket is mounted into the container; Container runs with root privileges
  • Lateral moves: Attackers can create new containers or modify existing ones via Docker API; Escalate privileges by exploiting container breakout techniques; Gain access to host filesystem and services through Docker operations
  • Impact: Complete compromise of host system through container escape and privilege escalation
  • Remediation: Remove Docker socket volume mount and run containers with non-root user through docker-compose.yml modification

2. Attack chain

  • Preconditions: Nginx allows underscores_in_headers; Gunicorn processes SCRIPT_NAME header; Flask route /admin/key exists
  • Lateral moves: Inject SCRIPT_NAME header to rewrite request path; Bypass Nginx deny rule for /admin/; Retrieve encryption key via /admin/key endpoint
  • Impact: Unauthenticated attacker can decrypt encrypted files and obtain sensitive information
  • Remediation: Disable processing of SCRIPT_NAME header in Gunicorn and remove /admin/key endpoint

3. Attack chain

  • Preconditions: 攻击者能够向服务器发送请求并控制请求头中的SCRIPT_NAME字段; Nginx配置中未正确限制/admin路径的访问; gunicorn未正确处理WSGI环境变量
  • Lateral moves: 攻击者可以通过设置SCRIPT_NAME请求头绕过Nginx的/admin路径限制; 攻击者可以构造请求如'/asdf/admin/key'并设置SCRIPT_NAME为'asdf/'以访问实际路径'/admin/key'; 攻击者可以利用获得的密钥解密加密的flag.txt.enc文件; 攻击者可以利用获得的密钥解密其他加密的敏感数据
  • Impact: 未经授权的密钥泄露可能导致敏感数据被解密, 影响系统的机密性和完整性
  • Remediation: 在server/server.py的get_key函数中添加对info['paid']字段的检查, 只有当已付费时才返回密钥
